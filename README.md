# Mini Project: ESP-NOW Remote & Battery Monitoring System

An IoT-based embedded system using ESP-NOW for wireless communication, web interface monitoring, and battery tracking.

---

## 📌 Features

* **Wireless Data Transmission:** Uses ESP-NOW protocol for low-latency communication between sender and receiver nodes.
* **Web Interface:** Web-based control and display panel for system status.
* **Battery Monitoring:** Tracks real-time power/voltage levels.
* **Documentation Included:** Contains full report (`Final Report.docx`) and presentation slides (`ppt_Mini project_final.pptx`).

# Mini Project: Autonomous Smart Wireless Drone Charging Pad

An IoT-based embedded system using ESP-NOW for low-latency wireless communication, real-time battery monitoring, and interactive web dashboard control.

---

## 📌 Features

* **Wireless Data Transmission:** Leverages ESP-NOW protocol for low-latency communication between transmitter and receiver modules.
* **Web Dashboard:** Interactive panel for status visualization and system controls.
* **Battery Monitoring:** Tracks real-time voltage and charging metrics.
* **Complete Documentation:** Includes project reports and presentation slides.
